## Purpose

This repository is not just source code. It is the implementation of a national-scale digital public infrastructure platform designed to improve internship allocation under the Prime Minister Internship Scheme.

The Engineering Constitution defines the philosophy, standards, architecture, engineering practices, design principles, and AI collaboration rules that govern every decision made in this repository.

Every human contributor and every AI coding assistant must follow these documents before implementing features. The Constitution exists to ensure that ATLAS remains scalable, maintainable, transparent, accessible, secure, explainable, and production-ready.

## Core principle

> Documentation is the source of truth. Code implements documentation. Code never defines architecture; architecture defines code.

## AI workflow

Before implementing any feature:

1. Read this Constitution and the relevant chapters.
2. Understand the product philosophy and applicable engineering constraints.
3. Summarize the implementation plan and affected boundaries.
4. Only then begin coding.

## Contributors

ATLAS is built collaboratively by human engineers and AI coding assistants. Every contributor must respect this Constitution. No implementation may violate the documented architecture without approval from the project architect.

## Living document

The Constitution is version controlled. Major architectural changes must update it before implementation, and the documentation always takes precedence over assumptions.
