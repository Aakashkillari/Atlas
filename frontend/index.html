Allocation Engine Pipeline

  1. Hard-Filter GateRule-based eligibility, capacity, location and date checks run before any scoring.
  2. Semantic MatchingVector similarity ranks candidate-internship fit by meaning, not keywords.
  3. Fairness WeightingEquity weighting adjusts for first-generation and tier-2/3 college applicants per policy.
  4. Hungarian OptimizationSolves the full pool simultaneously for a globally stable, high-quality allocation.
